# Arcadia Time

Máquina arcade de escritorio para Windows con minijuegos de estética pixel art "cute", menú principal, perfiles de usuario por nombre y récords por usuario y juego.

Proyecto de fin de grado, con ampliación posterior.

## Juegos

| Juego | Basado en | Resumen |
|---|---|---|
| Cutie Breaker | Brick Breaker | Rompe todos los bloques con la bola. Por niveles aparecen bloques más resistentes que dan más puntos. |
| Sweet Invaders | Space Invaders | La nave dispara sola y esquiva a los enemigos. Por niveles, enemigos más duros y con más puntos. |
| Antarctic Jump | Dinosaur game de Chrome | Un pingüino avanza y salta focas y pájaros. Cuanto más aguanta, más puntos y más velocidad. |

## Tecnología

- Unity 6.3 LTS (6000.3.27f1), plantilla Universal 2D
- C#
- Visual Studio Community 2026
- Control de versiones: Git y GitHub

## Cómo abrir el proyecto

1. Instalar Unity Hub y la versión 6000.3.27f1 (o la revisión más reciente de 6.3 LTS).
2. Clonar este repositorio.
3. En Unity Hub: Add > Add project from disk y seleccionar la carpeta clonada.
